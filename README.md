# Personal Expense Tracker

## Project Overview
A command-line Python application for recording, managing, reporting, and visualizing personal expenses.

## Features
- Add expenses
- View all expenses
- Categorize expenses
- Save and load data using CSV
- Overall spending report
- Category-wise report
- Monthly report
- Highest and average expense
- Search expenses by category
- Bar chart and pie chart visualization
- Input validation and exception handling

## Requirements
- Python 3.x
- Matplotlib

Install Matplotlib:
```bash
pip install matplotlib
```

## Run
```bash
python expense_tracker.py
```

The program automatically creates `expenses.csv` when you save your expenses.
